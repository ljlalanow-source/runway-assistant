# 나만의 비서 에이전트 템플릿 · RUNWAY

매일 아침, 내 비서가 텔레그램으로 먼저 말을 거는 에이전트를 만든다.

```
10월 9일 금요일 아침 브리핑 드려요!

☀️ 날씨
어제보다 아침이 조금 포근해요.
 🚶 출근길 체감 15°
 🚶 퇴근길 체감 22°
 👕 얇은 긴팔 하나면 충분해요. 낮엔 살짝 더울 수 있어요!

📅 오늘 일정
 · 12:30 👫 집들이
```

## 시작하기

1. 이 폴더를 내려받아 VS Code로 연다.
2. Claude Code에 이렇게 말한다.
   ```
   이 템플릿으로 내 비서 만들어 줘
   ```
3. Claude가 한 단계씩 안내한다. 막히면 화면을 캡처해서 붙여 넣고 물어본다.

## 준비물

- 휴대폰 (텔레그램 설치)
- GitHub 계정 (매일 자동으로 보내려면 필요)
- 캘린더를 연결하려면: 네이버 애플리케이션 비밀번호 / 애플 앱 암호 / 구글 캘린더 비공개 주소 중 하나

## 파일

| 파일 | 하는 일 |
|---|---|
| `CLAUDE.md` | 비서의 규칙표 (말투, 브리핑 형식) |
| `SETUP.md` | Claude가 따라가는 설정 순서 |
| `config.json` | 내 위치, 출퇴근 시간, 캘린더 (설정하면서 생긴다) |
| `collect.py` | 날씨, 일정, 할 일을 모아 온다 |
| `send.py` | 텔레그램으로 보낸다 |
| `find_calendars.py` | 내 캘린더 목록을 찾아 준다 (설정할 때만) |
| `.env` | 토큰과 비밀번호. **GitHub에 올라가지 않는다** |

## 리포터 템플릿

비서보다 리포터를 먼저 만들어 보면 좋다. 캘린더 연결 없이 봇, 규칙표, 예약을 한 바퀴 돌 수 있다.
